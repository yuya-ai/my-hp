📱 STEP 0: LINE予約デモ体験

5〜10分

つまり何するの？

お客様と同じ体験をしてみるだけ🌸

👤 やること

  1. Yuya のスマホのQRコードをスマホカメラで読み取る

🎨 Task 2: QRコード作成

10分

つまり何するの？

スマホでWebページを開いて、QR画像を写真フォルダに保存するだけ🌸

👤 やること

A. ブラウザでQRページを開く

  • Safari（iPhone）または Chrome（Android）
  • 下記URLを入力
https://my-hp-xi.vercel.app/qr.html

B. QR画像を長押し

画面中央のQRコード画像を長押し（タップしたまま動かさない）

C. 画像保存

  • iPhone: 「写真に追加」をタップ
  • Android: 「画像をダウンロード」をタップ

→ スマホの写真フォルダに自動保存される

✅ 完了チェック

  • QR画像を写真フォルダに保存

🖼 Task 3: ポップ作成

1〜2時間

つまり何するの？

Yuya からキャッチコピー案を受け取って、Canva でテンプレ選んで貼るだけ🌸

🤖 Yuya がやること

  • Claude Code で AI に依頼してキャッチコピー案を生成
  • LINE でまなみに送信

👤 まなみがやること

A. Yuya からキャッチコピーを受け取る

  • LINEで Yuya に「ポップのキャッチコピー案ちょうだい」と一言
  • Yuya が AI 生成した案を LINE で送ってくれる
  • 好きなものを1つ選ぶ

B. Canva でデザイン作成

  • Canva（https://www.canva.com/）にアクセス
  • Googleアカウントで無料登録
  • 検索：「ポスター A4 飲食店」
  • 好きなテンプレ選択
  • 編集画面で必要要素を入れる：
    • キャッチコピー（Aで選んだやつ）
    • QR画像をアップロード（Task 2で保存）
    • 操作手順 3ステップ（① QR読取 → ② 友だち追加 → ③ メッセージから予約）
    • 店舗情報（電話・営業時間）
  • 右上「共有」→「ダウンロード」→ PDF保存

C. 印刷

  • コンビニ印刷 or 自宅プリンタ
  • ラミネート加工（100均でOK・任意）

✅ 完了チェック

  • Yuyaからキャッチコピー受領
  • Canvaでデザイン完成
  • 印刷した紙が手元にある

🔐 Task 4: 公式LINE管理権限の引き継ぎ

30分

つまり何するの？

今まで Yuya だけが管理していた公式LINE を、まなみも管理できるよう権限追加するだけ🌸

🎯 目的

  • まなみが直接 公式LINEの設定・運用を管理できる
  • Yuya 不在時でも対応可能
  • 家族＋スタッフチームで運用

👤 まなみがやること

A. Yuya からの招待メールを確認

  • 件名：「LINE Official Account Manager への招待」
  • メール内のリンクをタップ

B. 招待を承認

  • LINE Official Account Manager にログイン（Googleアカウント or LINE）
  • 招待画面で「承認」をクリック

C. アクセス確認

https://manager.line.biz/

ログイン → ビオの公式アカウントが表示されればOK

🎁 これで何が便利？
・あいさつメッセージを自分で編集
・リッチメニュー（常駐ボタン）を自分で設定
・配信メッセージ（一斉案内）を自分で送信

✅ 完了チェック

  • 招待メール承認
  • LINE Official Account Manager にログイン成功
  • ビオの公式アカウントが見える
